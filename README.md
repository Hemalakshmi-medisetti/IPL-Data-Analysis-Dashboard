# 🏏 IPL Data Analysis Dashboard (2008–2025)

## 📌 Project Overview

This project is an interactive IPL Data Analysis Dashboard developed using Microsoft Excel. It covers IPL data from 2008 to 2025 and provides insights into team performance, toss decisions, player achievements and match statistics.

The main objective is to transform raw IPL data into meaningful insights through data analysis and visualization.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- VLOOKUP
- Slicers
- Charts and Data Visualization

## 📊 Key Analysis

1. **Team-wise Match Wins:** Batting First vs Bowling First.
2. **Toss Decision Analysis:** Batting vs Fielding decisions and winning percentage.
3. **Top 10 Venues:** Analysis of venues based on the number of matches.
4. **Player of the Match:** Player-wise award analysis.
5. **IPL Trophy Analysis:** Team-wise trophy counts.
6. **Season-wise IPL Details:** Winners, runners-up, Player of the Match and Player of the Season.

## ⭐ Dashboard Features

- Interactive dashboard using Excel Slicers.
- Pivot Table-based data analysis.
- VLOOKUP for retrieving season-wise information.
- Charts for visual representation of IPL statistics.
- Year-wise and team-wise analysis.
